# E-Commerce Sales Dashboard (Power_BI)

## Project Overview
This project focuses on analyzing E-Commerce sales performance using Power BI and Excel. The dashboard helps businesses understand sales trends, product performance, payment analysis, and customer purchasing behavior.

## Tools Used
- Power BI
- Excel
- Data Cleaning
- Data Visualization

## Dashboard Features
- Sales KPI Metrics
- Total Orders Analysis
- Average Order Value Analysis
- Sales Trend Visualization
- Product Category Analysis
- Payment Method Analysis
- Top Products Analysis
- Interactive Date Filters

## Key Insights
- Total sales reached approximately 1.26M.
- Furniture and Electronics categories generated higher revenue.
- Online payments contributed significantly to transactions.
- Top-performing products showed strong customer demand.

## Conclusion
The dashboard provides meaningful business insights that improve decision-making and sales performance.
